Modules
The directory, and its contents.
This is where you run Terraform "init", "plan", "apply", "destroy"
A module is a collection of *.tf and/or *.json files, considered to be a logical unit.
	A module can contain other modules.

Workspace


Command				Purpose
terraform init		Initialize the working directory. Downloads providers and modules, and sets up the backend.
terraform plan		Show what changes Terraform will make (create, update, or destroy resources) without actually doing them.
terraform apply		Apply the changes to reach the desired state defined in your configuration.
terraform destroy	Tear down all resources managed by the current Terraform configuration.

### Get the HashiCorp GPG Key

### then
### you can look over there for these new packages I'm asking form
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(grep -oP '(?<=UBUNTU_CODENAME=).*' /etc/os-release || lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
### then
### Check out what's new, with the new approved list of places to search in...

sudo apt install terraform
### then, verify your installation

README.md ....well....um.....
variables.tf declares variables
	This is a conventional name (not required by Terraform) for a file.
	It contains "variable blocks"
	These DECLARE input variables
	Declarations stay in the reusable .tf
terraform.tfvars assigns values to them.
	This is a special filename that Terraform automatically loads.
	It contains assignments that set concrete values for the variables you declared:
	The same config can be reused by swapping .tfvars files without changing the code.
		Think about it as you do exactly the same thing....
		...for Prod & Dev.....
		...you have a folder for Prod, and you have a folder for Dev....
		...but they have different "password repositories" that you need to use....
variables.tf says “these are the inputs this configuration accepts,”
...while terraform.tfvars says “here are the actual values for this run.”
